FA·CONTROLUSB FIRMWARE INSTALLER

▲ WEB SERIAL NOT AVAILABLE — USE CHROME OR EDGE ON A DESKTOP COMPUTER

WRITES THE COMPLETE FLASH PACKAGE — BOOTLOADER, PARTITION TABLE, OTA DATA AND FIRMWARE — STRAIGHT TO THE ESP32-C3 OVER USB. NO WI-FI, NO ESP-IDF INSTALLATION. USE THIS FOR A NEW BOARD, FOR A RESCUE, OR WHEN THE NAMES OR GAME ROMS MENU IS MISSING BECAUSE THE DEVICE HAS ONLY EVER SEEN OVER-THE-AIR UPDATES.

BEFORE YOU START
  • Set DIP 1 to ON. It is the power switch — in deep sleep the ESP32-C3 drops its USB-Serial/JTAG port and no device shows up in the browser dialog.
  • Use a USB-C cable with data wires. Charge-only cables give power and no port.
  • Make sure the machine is not under FA_Control's control right now — release it first, or simply power the pinball down.
  • Chrome or Edge on a desktop computer. Firefox and Safari have no Web Serial API.
